# Contributing to NASA Terminal Telemetry Console

Thank you for your interest in improving the terminal dashboard! We welcome contributions to help monitor real-time space telemetry.

## How Can I Contribute?

### Reporting Bugs
* Check the Issues tab to see if the bug has already been reported.
* If not, use our Bug Report template to open a new issue with clear replication steps.

### Suggesting Enhancements
* Open a new feature request issue to discuss your ideas.
* Describe the specific space array data or terminal feature you want to see.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. Ensure your Python code matches standard styling conventions.
3. Test your code to make sure the terminal UI loads properly without clearing user sessions abruptly.
4. Open a Pull Request with a clear description of your changes.
