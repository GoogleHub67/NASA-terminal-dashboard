<div align="center">
  <h1>NASA Terminal Telemetry Console</h1>
  <p>A Python-based terminal app to monitor open-source space data arrays.</p>
</div>

<hr />

## Mission Status Dashboard
<p>
  <strong>System Operation:</strong> Active<br />
  <strong>Primary Target:</strong> Mars Orbital Transition Arc<br />
  <strong>Launch Sequence:</strong> T-Minus 3... 2... 1... Ignition
</p>

<ul>
  <li><strong>ISS Tracker:</strong> Monitors current International Space Station orbital coordinates.</li>
  <li><strong>Asteroid Radar:</strong> Processes Near-Earth Object data structures to identify the closest flyby today.</li>
  <li><strong>Hardware Waveform Simulator:</strong> Uses trigonometric logic to generate a live signal animation.</li>
</ul>

<hr />

## Step 1: Download the Files
<p>Before running the dashboard, you must download this repository to your computer:</p>

<h3>Option A (Using Git)</h3>
<pre><code>git clone https://github.com/GoogleHub67/NASA-terminal-dashboard</code></pre>

<h3>Option B (Manual Download)</h3>
<ol>
  <li>Click the green <strong>Code</strong> button at the top of this page.</li>
  <li>Click <strong>Download ZIP</strong>.</li>
  <li>Extract the downloaded folder on your desktop.</li>
</ol>

<hr />

## Step 2: Run the Application

<h3>Windows Users</h3>
<ol>
  <li>Open the extracted project folder.</li>
  <li>Double-click <strong><code>launch_win.bat</code></strong> (It will handle terminal navigation automatically).</li>
</ol>

<h3>macOS / Linux Users</h3>
<ol>
  <li>Open your Terminal application.</li>
  <li>Navigate into the folder using the change directory command:</li>
  <pre><code>cd ~/Desktop/nasa-terminal-dashboard</code></pre>
  <li>Execute the launcher script:</li>
  <pre><code>chmod +x setup_mac_linux.sh && ./setup_mac_linux.sh</code></pre>
</ol>
