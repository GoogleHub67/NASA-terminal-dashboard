# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Please do not open a public GitHub issue for security bugs regarding telemetry streams or system console exploits. Instead, contact the maintainer directly through the profile contact information. We will investigate the issue and push a fix as soon as possible.
